# DRubySE.com Redesign

Official portfolio and constructability engineering legacy of **David I. Ruby, PE, SE, FASCE** (Constructability Consultant & Structural Steel Specialist).

## 🚀 Live Features
- **Modern White Architectural Theme** (default) + One-Click **Dark Titanium Theme Toggle**
- **21 Landmark Engineering Projects** with local high-resolution imagery and interactive blueprint lightbox dialogs
- **AISC Design Guide #23: Constructability of Structural Steel Buildings** showcase with 12 Core Constructability Principles
- **Historic Career Timeline (1956 – Present)**: American Bridge Division, John Portman & Associates, Ruby+Associates, and Degenkolb
- **Industry Honors**: Michigan Construction Hall of Fame (2023), AISC J. Lloyd Kimbrough Award (2022), AISC Lifetime Achievement Award (2011)
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3, and vanilla JavaScript

## 📦 How to Deploy to Vercel
1. Push this repository to your GitHub account (see instructions below).
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the `drubyse-redesign` repository.
4. Leave build settings as default (Other / Static Site).
5. Click **Deploy**!
